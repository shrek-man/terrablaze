Get a free key from NASA FIRMS. Paste it here or choose a .txt file containing only the key. Select Load live data to send it to the local app server. It is kept in this browser tab’s session storage until you clear it.

FIRMS queries a rectangle; live hotspots are clipped to India's boundary. The app tries several OpenStreetMap Overpass servers, then uses its bundled boundary if they are unreachable. Site distances need an Overpass connection.

Historical archive availability varies by satellite and date. NASA currently lists MODIS, NOAA-20, and Suomi-NPP standard products; NOAA-21 is available in the recent feed. Industrial context uses today's OpenStreetMap data, not archived infrastructure.
